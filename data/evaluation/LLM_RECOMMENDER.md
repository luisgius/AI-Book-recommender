## Design (fixed in advance)

Systems:

- `pipeline`: R0: `hybrid_norm_e5_bge` of V06 (hybrid_norm_e5 + BAAI/bge-reranker-v2-m3 over the top 30); no LLM in the ranking
- `rag_llm_recommender`: R1: top 30 of `hybrid_norm_e5` re-ordered by one listwise LLM call (LLMListwiseReranker in SearchService)
- `long_context_recommender`: R2: no retrieval; one LLM call with the whole catalog returns 10 ids
- `closed_book_recommender`: R3: no catalog; the LLM names 10 real books (title, author), matched to the catalog
- `hybrid_norm_e5`: Reference (descriptive): `hybrid_norm_e5` of V06, the candidate generator of R1, without reranker

Pre-declared contrasts (nDCG@10, system - reference): L1 `rag_llm_recommender` - `pipeline` (Does the RAG LLM recommender (R1) improve on the pipeline (R0)?); L2 `long_context_recommender` - `pipeline` (Does the long-context LLM recommender, without retrieval (R2), improve on the pipeline (R0)?). Two-sided paired randomisation test (sign flips) on per-query nDCG@10, 10000 resamples, seed 0; Holm correction across exactly L1 and L2; paired percentile bootstrap 95% CI over queries (10000 resamples, seed 0).

Descriptive only: Recall@10, P@5 and MRR, the en/es breakdown, R3 and the `hybrid_norm_e5` reference row, grounding, cost, scaling, determinism (run 2).

Grounding rules: Each book is shown with an id B1..Bn (R1: fused order; R2: catalog sorted by source and source_id). A returned id is read trimmed, without brackets and in upper case; ids that were not shown are dropped and counted, and so are repeated ids. If fewer than 10 valid ids come back, the top 10 is completed with the remaining candidates in the order they were shown (fused order for R1, catalog order for R2); an unusable answer counts as zero valid ids.

R3 matching rule: a closed-book recommendation matches a catalog book when both titles are equal after normalisation (lower case, accents removed, every run of non-alphanumeric characters as one space), each cut before the first ':', '(', '[' or ' - ' (subtitles and edition notes ignored), and the last word of the recommended author's surname (the words before a comma, otherwise the last word; only the first of several authors) equals that of one of the book's authors. The first matching catalog book is taken; a book matched twice in one list is ranked once.

## Prompts (as used)

listwise system:

```
You are a book recommender for a library catalog. You may only recommend books from the list you are given, and you refer to each book by its id.
```

listwise user:

```
Books:

{books}

Query: "{query}"

Choose the {n} books from the list that best match the query, best first. Use only ids from the list, each at most once. For each book give its id and one short sentence, in the language of the query, saying why it matches.
```

closed-book system:

```
You are a book recommender.
```

closed-book user:

```
Query: "{query}"

Recommend the {n} real, published books that best match the query, best first. For each book give its exact title, its main author, and one short sentence, in the language of the query, saying why it matches.
```

Each book in the list (example, first book of the R2 catalog order):

```
[B1] title: Historia de la literatura española; authors: Ezequiel González Mas; year: 1968; language: es; categories: Spanish literature
description: (none)
```

## Reproduce

```
python -m app.evaluation.llm_recommender_evaluation
python -m app.evaluation.llm_recommender_evaluation --no-llm
```

The first command calls the system LLM and the judge only for what is not cached (`data/evaluation/llm_recommender/qwen-qwen3.8-flash__prompt-v1.0.jsonl`, `data/evaluation/llm_judgments/z-ai-glm-5.3-flash__prompt-v1.0.jsonl`); the second calls no LLM and fails if any output or judgment is missing. Both run the local retrieval models (e5, bge), so their latencies are re-measured on every run; every other number comes from the caches.
